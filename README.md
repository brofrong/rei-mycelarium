# rei-mycelarium

Неофициальный нативный порт игры [Mycelarium](https://store.steampowered.com/app/5181520/) на macOS.
В репозитории две версии: на [LÖVE](https://love2d.org) (Lua) и на Rust + [Bevy](https://bevyengine.org).

## Нужна лицензия из Steam

**В репозитории нет ни одного файла игры:** ни графики, ни звуков, ни текстов, ни исполняемых файлов.
Сборка извлекает ресурсы из твоей собственной копии игры. Без купленной Mycelarium собрать ничего не получится.

👉 **[Купить Mycelarium в Steam](https://store.steampowered.com/app/5181520/)**

Не выкладывай собранные приложения и извлечённые ресурсы в открытый доступ: они принадлежат авторам игры.

## Зачем это всё

Проект сделан исключительно ради изучения возможностей ИИ (почти весь код написан с помощью Claude Code)
и потому, что версии игры для macOS нет, а поиграть очень хотелось.
Это не официальный продукт, к разработчикам игры проект отношения не имеет.

## Как собрать

Нужен Mac (проверено на Apple Silicon, macOS 12+), Python 3 и Xcode Command Line Tools.

### 1. Достань файлы игры

Нужна Windows-версия игры (папка с `Mycelarium.exe` и `data.win`). Варианты:

- установить игру через Steam на Windows-машине или через CrossOver / GameHub и скопировать папку;
- скачать через [SteamCMD](https://developer.valvesoftware.com/wiki/SteamCMD), принудительно выбрав Windows-платформу:

  ```sh
  steamcmd +@sSteamCmdForcePlatformType windows +login <твой_логин> +app_update 5181520 validate +quit
  ```

По умолчанию инструменты ищут игру в `~/GameHub/steamapps/common/Mycelarium`.
Если она лежит в другом месте, укажи путь в `MYCO_GAME_DIR` (для иконки Rust-версии — в `GAME_EXE`).

### 2. Извлеки ресурсы

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements.txt
.venv/bin/python -I tools/extract.py        # → build/assets/
```

### 3a. LÖVE-версия

Скачай `love-11.5-macos.zip` со [страницы релизов LÖVE](https://github.com/love2d/love/releases),
распакуй `love.app` в `build/tools/love.app` и запусти:

```sh
tools/package.sh                            # → dist/Mycelarium.app
```

### 3b. Rust-версия

Нужны [Rust](https://rustup.rs) и `jq` (`brew install jq`):

```sh
tools/package_rust.sh                       # → dist/Mycelarium Rust.app
```

Первая сборка занимает несколько минут.

### Сохранения

Обе версии используют одну папку сохранений — `~/Library/Application Support/Mycelarium`
и один формат, так что игру можно продолжать то в одной, то в другой версии.

## Rust-версия: небольшие доработки от меня

LÖVE-версия повторяет оригинал. В Rust-версию я добавил кое-что от себя:

- ПКМ сразу ставит узел, при неудаче у курсора всплывает подсказка;
- зум камеры колесом и щипком, от верхушек деревьев до воды;
- всплывающие «+N / −N» еды и воды, иконки еды красные, воды синие;
- постройка нескольких грибов подряд с зажатым Shift и счётчик грибов каждого типа;
- кнопка «Продолжить» и автозагрузка последнего сейва при запуске;
- маркеры зверей видны при любом отдалении, клик переносит к зверю;
- дополнительные синие пещеры, пещера света появляется через час игры и отмечена маркером;
- сохранение по Cmd+Q, журнал ошибок в `~/Library/Logs/Mycelarium Rust/panic.log`.

## Что я понял: LÖVE против Rust

**LÖVE-версия оказалась намного удобнее для разработки с ИИ.** Lua-код близок к оригинальному GML,
правки проверяются мгновенно, без компиляции.

**Rust был ошибкой.** Приложение весит больше (73 МБ против 47 МБ у LÖVE), производительности
для такой игры не добавляет, а из-за медленного компилятора каждая фича делается дольше.
Строгая типизация ловит часть ошибок, но для 2D-игры такого размера это того не стоит.
